# App Isis para celular

Esta carpeta contiene la versión instalable de App Isis.

## Publicación necesaria

Para instalarla como app, estos archivos deben publicarse juntos en una dirección segura HTTPS. Abrir `index.html` como archivo descargado no alcanza para instalarla: el navegador requiere que la web esté servida desde HTTPS o desde `localhost`.

## Android

1. Abrí el enlace HTTPS en Chrome.
2. Elegí **Instalar aplicación** o **Agregar a pantalla principal** en el menú del navegador.

## iPhone

1. Abrí el enlace HTTPS en Safari.
2. Tocá **Compartir** y elegí **Agregar a pantalla de inicio**.

Los archivos base de la app quedan disponibles sin conexión después de la primera apertura. La lectura automática de tickets requiere internet para cargar el OCR y el idioma español.

Los datos quedan guardados en ese navegador y dispositivo. Para llevar los datos que ya cargaste a la versión instalada, exportá la copia JSON desde la app e importala luego en la versión publicada.
